# Отчёт о работах за 28.10.2026

## Цель дня

Объединить OpenGlass и Classic Shell/Open-Shell в одном русскоязычном центре управления для Windows 10, сохранив стеклянное оформление и не вмешиваясь в работу Проводника без необходимости.

## 1. Подготовка сборочной среды

- Проверен исходный проект OpenGlass.
- Подготовлена сборка под Windows 10 x64.
- Использован MSVC v143 из Visual Studio 2022 Build Tools.
- Использован Windows SDK 10.0.26100.0.
- Настроен локальный статический набор зависимостей wxWidgets, NanoSVG, libpng, zlib и связанных библиотек.
- Устранена несовместимость устаревшей зависимости `wxregexu.lib`.
- Создана рабочая ASCII-копия каталога зависимостей для обхода проблем путей с кириллицей.

## 2. Интеграция Classic Shell

Создан файл `OpenGlassGUI/MainFrame.ClassicStartMenu.cpp`.

Добавлен отдельный раздел с названием:

> Меню Пуск и панель задач

В него перенесены основные параметры текущего профиля Classic Shell:

- включение меню Пуск;
- включение кнопки Пуск;
- пропуск стартового экрана Metro;
- стиль меню Win7/Classic;
- скин Windows 7;
- вариант скина;
- тип и изображение кнопки Пуск;
- стекло меню;
- цвет и прозрачность стекла;
- пользовательская панель задач;
- вид и прозрачность панели задач;
- цвет, текстура и режим растяжения текстуры панели задач;
- параметры `SkinOptionsW7`.

`SkinOptionsW7` теперь читается и сохраняется как `REG_MULTI_SZ`, а не как обычная строка. Изменения флажков не теряются при сохранении и возврате настроек.

Перенесены основные визуальные принципы:
