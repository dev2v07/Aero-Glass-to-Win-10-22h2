# Aero Glass UI — отчёт о принятой версии

Дата: 28 октября 2026 г.

## Статус

UI-версия принята пользователем для текущего этапа.

## Зафиксированный результат

- Нативная рамка Windows заменена собственным glass-header с управлением окном.
- Реализованы Acrylic/Blur и сохранение параметров оболочки приложения.
- Первый запуск использует Acrylic + Blur; после сохранения загружаются сохранённые значения.
- Тёмная базовая поверхность приложения — `#000000`.
- Добавлены настройки цвета оболочки, прозрачности, Acrylic, Blur и accent-цвета.
- Accent применяется к активной навигации и иконкам; контраст текста выбирается автоматически.
- Навигация получила Figma-иконки, левый якорь 10 px и расширенную боковую панель.
- Кнопка «Настройки приложения» вынесена вниз боковой панели и расширена.
- Кнопки переведены на собственную прозрачную glass-отрисовку с тонким контуром.
- Поля и controls используют палитру выбранной оболочки/темы.
- Исправлено перепалитрирование светлой/тёмной схемы для всего окна и страниц.
- File picker Browse-кнопки оставлены на штатных обработчиках wxWidgets.
- Добавлен footer: `© Разработано Tandem Marketing 2026`.

## Проверка

- Конфигурация: `Release | x64`.
- Toolset текущей среды: MSVC v143.
- Результат последней сборки: 0 ошибок; остаются предупреждения внутри NanoSVG third-party header.
- Runtime smoke check: `OpenGlassGUI.exe` запускается и отвечает.
- Проверен визуальный результат собственного окна, навигации, accent-контраста и footer.

EXE: `C:\projects\Aero Glass\Build\x64\Release\common\OpenGlassGUI.exe`

## Граница зафиксированной версии

Это принятая UI-основа и не означает пиксельную замену всех wxWidgets controls на кастомный canvas. Системные file picker, sliders и часть сложных controls сохраняют нативное поведение Windows, но используют общую палитру интерфейса.
