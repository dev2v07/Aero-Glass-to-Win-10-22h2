# AeroBoot

Собственный безопасный прототип EFI-приложения Aero Glass. На текущем этапе
он только собирается как `UEFI_APPLICATION` и не устанавливается в EFI-раздел.

## Поведение прототипа

1. Находит GOP и файловую систему, с которой запущен `AeroBoot.efi`.
2. Читает `\\EFI\\AeroBoot\\animation\\activity000.bmp` ... `activity104.bmp`.
3. Проверяет BMP как 24-bit uncompressed BMP и рисует кадры по центру экрана.
4. Показывает 105 кадров с интервалом около 66,7 ms.
5. Передаёт управление сохранённому `\\EFI\\AeroBoot\\bootmgfw-original.efi`; если
   он недоступен, используется штатный `\\EFI\\Microsoft\\Boot\\bootmgfw.efi`.

Проверенные кадры для сборки находятся в `AeroBoot/assets/animation/`.

Путь к оригинальному загрузчику намеренно фиксирован и не перезаписывает
`\\EFI\\Microsoft\\Boot\\bootmgfw.efi`.

## Ограничения текущего прототипа

- Secure Boot-подпись, резервирование EFI-раздела, BCD и rollback ещё не
  реализованы.
- Нельзя устанавливать этот прототип на рабочую систему.
- Если файл кадра отсутствует или имеет неподдерживаемый BMP-формат, приложение
  пропускает анимацию и пытается сразу запустить штатный Windows Boot Manager.
- Для ограничения зависания установлен EFI watchdog на 20 секунд; перед
  chainload он отключается.
- В консоль EFI выводятся этап запуска, режим GOP, проблемный кадр и результат
  chainload. Это диагностический вывод, а не постоянный файл-журнал.
- Чтение кадров ограничено 8 MiB; BMP проверяется на допустимый заголовок,
  размеры, арифметическое переполнение, 24-bit BGR и отсутствие сжатия.
- Атомарный установщик для тестового диска, резервирование ESP, BCD и rollback
  остаются отдельным следующим этапом.

## Сборка

Сборка рассчитана на EDK II BaseTools и стандартные пакеты `MdePkg` и
`MdeModulePkg`. Для воспроизводимой сборки используется
`AeroBoot/AeroBoot.dsc`:

```powershell
pwsh .\Scripts\Build-AeroBoot.ps1 -Edk2Path C:\path\to\edk2
```

Скрипт только вызывает EDK II build и не устанавливает EFI-файл, не меняет ESP
и не изменяет NVRAM. По умолчанию используется `RELEASE|X64|VS2022`; цель можно
сменить параметром `-BuildTarget`.

Установка на ESP и изменение NVRAM намеренно не входят в эту сборку.
